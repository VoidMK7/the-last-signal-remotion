# The Last Signal — The Price of Tomorrow

A Remotion + Three.js cinematic story prototype. The original composition is preserved as `TheLastSignal`; the new story-first 3D prototype is `TheLastSignal3D`.

## Run in GitHub Codespaces

```bash
npm install
npm run start
```

In Remotion Studio choose **TheLastSignal3D** from the composition selector. The project uses a procedural Three.js Lagos-inspired city environment and an original generated ambient score (`public/audio/original-score.mp3`).

## Render

```bash
npm run build:3d
```

Output: `out/the-last-signal-3d.mp4`.

## What's included

- Eight-act story arc: family hardship, breakup, learning, memecoin setbacks, persistence, fictional $100M portfolio valuation, family payoff, and reflective ending.
- A Three.js procedural city, road, buildings, low-poly Malik character, lighting and camera movement.
- Remotion titles, narration-style on-screen story lines and a generated original ambient music bed.
- Full screenplay in `SCREENPLAY.md` and audio cue sheet in `AUDIO_CUES.md`.

## Important production note

This is a working visual prototype, not a finished feature-quality character animation. The initial 3D character is deliberately a low-poly placeholder; replace it with custom rigged `.glb` character/environment assets for expressive acting and close-ups. The music file is an original synthesized placeholder score, not a recorded orchestra or voice-over. Add recorded narration and dedicated sound effects before final release.

The $100 million outcome is fictional and exceptional. Memecoins are highly volatile; the story does not present trading as a dependable way to make money.
